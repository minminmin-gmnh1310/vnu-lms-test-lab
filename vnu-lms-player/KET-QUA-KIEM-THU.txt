GIỚI HẠN BẰNG CHỨNG
Đây là kiểm thử Node/DOM, không phải chạy Edge/Chrome trên Windows thật.
Media/play(), hình học, focus/visibility, timer và số phút server đều mô phỏng.
Số phút server mô phỏng được cấp độc lập với bộ đếm tiện ích.
Chưa đăng nhập VNU thật để kiểm tra autoplay, callback chậm thật, cấu trúc
các môn khác, vòng đời biểu mẫu hoặc cách server ghi phút.
20 ca dùng hai HTML đầy đủ của bản 0.8.1 không được chạy lại ở lượt này;
hai HTML và script kiểm thử riêng không nằm trong ZIP. Không tính chúng vào 295.
Các selector đã biết vẫn được kiểm tra bằng fixture có cùng cấu trúc DOM.

LMS đã ghi nhận lấy từ bảng tiến trình mà trang hiển thị. Tool không tự gọi
API ghi phút, tạo heartbeat hoặc xác nhận server đã làm mới chỉ từ tuổi dữ liệu.
Chỉ trạng thái Đã hoàn thành từ LMS mới được xác nhận. Mục yêu cầu trả lời/nộp
vẫn cần người học thực hiện; iframe cần bấm Giữ biểu mẫu trước khi trả lời.

CHẠY LẠI
Cài Node.js; trong vnu-lms-player chạy npm install, npm test, npm run check.
Test chạy lần lượt để giảm số tiến trình và bộ nhớ sử dụng đồng thời.
Tiện ích không cần Node.js để chạy trên Edge/Chrome.
